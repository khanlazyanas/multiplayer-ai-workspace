# 🚀 Multiplayer AI Workspace

An enterprise-grade, real-time collaborative workspace built for seamless team productivity. This application combines a rich text document editor with an infinite WebGL-based canvas, allowing multiple users to brainstorm, design, and write simultaneously with zero latency.

## ✨ Key Features

* **Real-time Collaboration:** Powered by Liveblocks for instant sync, live cursors, and active presence indicators.
* **Infinite Canvas:** Integrated with Tldraw for a high-performance, WebGL-driven whiteboarding experience.
* **Rich Document Editor:** Advanced text editing capabilities running in parallel with the canvas.
* **Secure Authentication:** Complete user identity management and protected routes using Clerk.
* **Shareable Workspaces:** Generate unique, secure links to invite team members to specific rooms instantly.
* **Responsive UI:** A beautifully crafted, dark-mode optimized interface built with Tailwind CSS.

## 🛠️ Tech Stack

* **Framework:** Next.js 14 (App Router)
* **Language:** TypeScript
* **Collaboration Engine:** Liveblocks
* **Whiteboard/Canvas:** Tldraw
* **Authentication:** Clerk
* **Styling:** Tailwind CSS
